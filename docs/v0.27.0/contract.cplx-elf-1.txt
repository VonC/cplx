# CPLX-ELF/1 contract corpus.

# Committed test data. Authored BY HAND from the reviewed design's grammar
# (design.v0.27.0.relocation-force-rpath.md, Design Area 3), which is rank 1
# semantic authority. This file is rank 2: the frozen executable witness.
# The formatter and the reader are rank 3, and a mismatch presumes THEY are
# wrong. See ledger.cplx-elf-1.md for the two-way derivation audit.
#
# Neither production end sources constants from this file, and this file was
# not generated from either end's vocabulary tables. A corpus derived from the
# formatter would agree with the formatter by construction and prove nothing.
#
# FORMAT. One vector per line, fields separated by the pipe character. No
# record value can contain a pipe or a semicolon, so both are safe delimiters.
#
#   canonical-obj  | id | record
#   canonical-end  | id | record
#   reader-valid   | id | record            accepted, formatter need not emit
#   rejected       | id | reason | record
#   path           | id | raw-spec | expected-hex
#   capture-valid  | id | record;;record;;...
#   capture-reject | id | reason | record;;record;;...
#
# RAW-SPEC ESCAPES for the path matrix. Named and decimal on purpose: an escape
# written in hex would express the input in the very encoding under test.
#
#   %SP%    one space, 0x20
#   %NL%    one line feed, 0x0A
#   %B255%  the single byte whose decimal value is 255
#   %DEST%  the walked root DEST_PATH; the encoded value is what FOLLOWS it
#
# CANONICAL FIELD ORDER, from the design's sample capture:
#   obj: case rpath interp path
#   end: state reason walked r-rewritten r-failed r-already-correct
#        r-not-dynamic r-excluded i-rewritten i-failed i-unchanged
#        i-not-applicable mig-checked mig-failed
